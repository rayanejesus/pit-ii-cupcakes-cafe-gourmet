# 9. Relatório de qualidade

**Projeto:** Loja Virtual de Cupcakes e Cafés Gourmet
**Data:** preencher após execução final
**Versão:** 1.0.0

## Evidências

Os testes automatizados devem ser executados com `pytest` no backend e `npm test`/`npm run build` no frontend. Os resultados reais devem ser registrados nesta seção; não são presumidas avaliações de usuários ou capturas de tela.

## Pendências

- Autenticação e autorização por perfil.
- Interfaces administrativas e de entregador.
- Teste Playwright e avaliação com cinco usuários reais.
