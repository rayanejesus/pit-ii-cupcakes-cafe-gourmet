# Roteiro de testes manuais — versão 1.0

## Orientações ao avaliador

Execute as tarefas na ordem, sem receber ajuda durante o primeiro percurso. Use dados fictícios; não informe senhas, números reais de cartão ou outros dados sensíveis. Registre o resultado imediatamente após cada tarefa.

Para cada tarefa, marque **Concluída**, **Parcial** ou **Não concluída** e anote uma evidência observável, como o texto exibido, a tela, o valor calculado ou uma mensagem de erro. O roteiro não pressupõe que alguma tarefa será aprovada.

## Pré-condições

1. A aplicação web e a API devem estar em execução conforme [`03-instrucoes-execucao.md`](./03-instrucoes-execucao.md).
2. O banco deve conter os dados demonstrativos.
3. O navegador deve estar em uma janela limpa ou em modo anônimo.
